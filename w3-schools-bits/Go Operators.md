Go Operators are simple signs that do math or make decisions.
Main ones:

Arithmetic: + - * / %   (add, subtract, multiply, divide, remainder)
Comparison: == != > < >= <=   (equal, not equal, greater, smaller)
Logical: && || !   (and, or, not)

Simple example:
Goa := 10
b := 3
sum := a + b     // 13
isBig := a > b   // true
