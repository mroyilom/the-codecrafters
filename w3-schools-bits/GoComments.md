# Go Comments

Go comments are statements by the code writer. These comments do not affect the code.

In Go, comments are defined using `//` (two forward slashes).

Any text between `//` and the end of the line is ignored by the compiler and will not be executed. This type of comment is usually for a single line.

To write a multi-line comment, use:

```go
/* The code below will print Hello World
to the screen, and it is amazing */
```

This starts with a forward slash followed by an asterisk `/*` and ends with `*/`.
