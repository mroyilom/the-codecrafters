# Go Syntax

This introduction focused on the basics of Go programming language, its advantages over other programming languages and its limitations as well.

There are certain basics in Go, the program will work. These include:

* Package declaration
* Import packages
* Functions
* Statements and expressions

Line 1: In Go, every program is part of a package. We define this using the `package` keyword. In this example, the program belongs to the `main` package.

Line 2: `import ("fmt")` lets us import files included in the `fmt` package.

Line 3: A blank line. Go ignores white space. Having white spaces in code makes it more readable.

Line 4: `func main() {}` is a function. Any code inside its curly brackets `{}` will be executed.

Line 5: `fmt.Println()` is a function made available from the `fmt` package. It is used to output or print text. In our example it will output `"Hello World!"`.

These basics are present in every program.
